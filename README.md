# Mansión embrujada

Casa embrujada interactiva desarrollada exclusivamente con Three.js, cuyo objetivo fue explorar el funcionamiento de la librería, el movimiento e interacción de objetos en un entorno 3D y la detección de acciones del usuario, prestando especial atención al diseño y a la optimización del rendimiento y la memoria.
